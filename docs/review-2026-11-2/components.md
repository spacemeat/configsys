## Patterns (fix once, not per unit)

- **EPEL / EL gating — 103 findings (69 name EL 10).** Two shapes: a `redhat` binding that needs EPEL on EL but lacks `requires: epel` (fails on stock EL), and `requires: epel` on packages EL ships itself or that EPEL 10 doesn't carry yet. Same root as os-releases.md §2's EL 10 sweep (64 missing). One pass over every `rhel`-reachable native binding, release-scoped (`rhel >= 10`), fixes both.
- **Native package names — 127 findings.** Mostly Void `-devel` splits (a lib component's `default:` name installs the runtime, not the headers), Tumbleweed's versioned packages (blender-5.2), Amazon Linux absences on bindings that name `amzn`. A per-manager lint (lib components must name the dev package on xbps/dnf/zypper) would catch the Void class mechanically.
- **License / telemetry / attrs drift — 33 findings.** Relicensings and phone-home changes found by hand research (no token): see the drift list.
- **Vendor repos — 33 findings** (rotated keys, moved repo URLs, codename-pinned source lines).
